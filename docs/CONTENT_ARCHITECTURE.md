# Content Architecture

## Core Shift

Web Growth should evolve from a standard blog into an **Academy**.

The Academy is not just a publishing section. It is a structured learning and trust engine that supports:

- SEO traffic
- AdSense revenue
- service conversion
- digital product sales
- tool adoption

## Academy Structure

Visible label:

- Academy

Current URL constraint:

- preserve `/blog/` until a deliberate migration is planned

## Pillars

Primary pillars for long-term content scaling:

1. Google AdSense
2. SEO
3. Website Design
4. Website Speed
5. Lead Generation
6. AI for Websites
7. Case Studies

10. Templates
11. Glossary

## First 100 Article Strategy

Do not blindly rush to 100 posts.

Structure the first 100 like this:

- 20 cornerstone guides
- 20 checklist/template/tool support articles
- 20 high-intent service-support articles
- 15 local / conversion / implementation guides
- 15 monetization and AdSense guides
- 10 glossary or concept pages only if they are fully useful

## Recommended Early Priority Clusters

1. Website redesign and audit cluster
2. Service page and conversion cluster
3. Local SEO and Google Business Profile cluster
4. Website speed and hosting cluster
5. Tracking / analytics / attribution cluster
6. AdSense approval and publisher quality cluster

## Internal Linking Model

Each piece of content should connect across four levels:

1. same-pillar articles
2. adjacent-pillar articles
3. relevant service pages
4. relevant tools/checklists/templates

Target:

- every Academy article: at least 3 contextual internal links
- every service page: at least 3 contextual internal links

## Article Template

Each Academy article should include:

- primary keyword
- search intent
- SEO title
- meta description
- H1
- direct opening answer
- problem framing
- practical explanation
- examples
- internal links
- FAQ
- service/tool escalation path
- author block
- reviewer block where applicable
- updated/reviewed date

## Category Landing Page Template

Each future Academy pillar page should include:

- pillar definition
- who it is for
- what readers will learn
- featured guides
- beginner path
- implementation path
- related services
- related tools

## Learning Paths

Future learning paths should group articles by user goal, not just topic.

Examples:

- Launch a high-converting business website
- Get AdSense approval safely
- Improve local SEO and Google Maps visibility
- Make your website faster and more trustworthy
- Build service pages that generate enquiries

## Repo-Specific Notes

- Current content already has strong frontmatter fields in `src/lib/posts.ts`.
- Governance already controls public article visibility.
- Use the current blog system as the Academy backend until a route migration is intentionally planned.
- Existing strong pieces should be improved and repositioned before mass new publishing.
