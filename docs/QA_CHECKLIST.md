# QA Checklist

## Pre-Build Checks

- page purpose is clear
- route already exists or is intentionally planned
- no conflict with route governance
- copy is specific and useful
- metadata approach is defined

## Post-Build Checks

- page renders correctly
- layout works on mobile and desktop
- links work
- CTA paths work
- no console errors

## SEO Checks

- unique title
- unique meta description
- canonical present
- robots intent correct
- sitemap intent correct
- schema valid and truthful
- internal links present
- no accidental orphaning

## Accessibility Checks

- single H1
- semantic sections
- keyboard navigation works
- focus states visible
- alt text correct
- accordions/menu/buttons have proper labels
- no critical contrast problems

## Performance Checks

- no unnecessary client rendering
- images optimized
- no giant background images where semantic images are better
- third-party scripts justified
- motion restrained
- no obvious layout shift traps

## Mobile Checks

- nav works
- forms are usable
- buttons are large enough
- text wraps properly
- no overflow
- hero remains readable

## Content Checks

- no encoding damage
- no AI filler
- no repeated weak phrasing
- examples are specific
- article/service intent is clear
- trust claims are supportable

## AdSense Checks

- page is substantial enough
- legal/trust pages remain complete
- no deceptive layout patterns
- no thin monetization page
- ads are not planned in inappropriate areas

## Conversion Checks

- primary CTA is obvious
- secondary CTA does not compete badly
- form path is clear
- trust signals appear before hard asks where needed
- service pages and Academy pages escalate naturally

## Final Launch Checks

- lint passes
- typecheck passes
- build passes
- sitemap generation passes
- robots output is correct
- noindex pages remain excluded from core IA
- indexed pages are indexable and intentional
