# Rebuild Roadmap

## Phase 1: Audit Current Site

- confirm route inventory
- confirm governance and sitemap behavior
- confirm current service/page purpose
- confirm current blog-to-Academy transition constraints
- confirm trust/legal completeness

## Phase 2: Design System

- finalize premium platform direction
- define homepage layout hierarchy
- standardize cards, sections, CTA patterns, and page shells
- reduce visual inconsistency between custom and templated pages

## Phase 3: Homepage Rebuild

- reposition homepage from launch-offer-first to platform-first
- explain Web Growth clearly
- introduce services, Academy, tools, and proof in one coherent flow
- keep a strong commercial CTA

## Phase 4: Academy Architecture

- rename visible Blog label to Academy
- create pillar structure
- define learning paths
- improve Academy hub discoverability

## Phase 5: Article Template

- standardize article headers
- improve TOC, trust, FAQ, and related resource blocks
- tighten internal linking and monetization-safe CTA model

## Phase 6: Service Pages Upgrade

- unify service page framework
- improve differentiation
- strengthen proof, FAQs, fit filters, and related content links

## Phase 7: Free Tools Section

- define utility IA
- build safe public tool templates
- connect tools to Academy and service journeys

## Phase 8: Case Studies

- turn portfolio proof into stronger case study assets
- improve evidence structure
- connect case studies to relevant services and Academy content

## Phase 9: SEO / Schema Implementation

- tighten metadata consistency
- improve schema specificity
- refine pillar/category IA
- confirm internal linking at scale

## Phase 10: AdSense Readiness

- add or strengthen disclaimer
- remove thin/risky pages from monetization consideration
- confirm Academy quality and trust standards
- define safe ad placements

## Phase 11: QA And Launch

- full lint/typecheck/build pass
- route validation
- sitemap/robots verification
- manual mobile/desktop QA
- content quality pass
- pre-AdSense review pass

## Repo-Specific Rebuild Principles

- preserve route governance
- keep existing SEO equity where possible
- do not expose noindex campaign pages in the main IA
- keep internal utilities internal
- do not rush large URL changes before redirect planning
