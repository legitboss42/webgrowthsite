# Schema Report

## Changes

- Retained one sitewide WebSite, organization/service entity, and founder Person graph in the root layout.
- Retained page-specific Service, WebPage, BlogPosting, ImageObject, and BreadcrumbList markup where supported.
- Removed FAQPage JSON-LD while retaining visible FAQ content.
- Removed duplicated homepage entities, hard-coded offer pricing, a city-only postal address, and unverified social profile URLs.
- Removed promotional Offer markup from the noindex hosting page.

## Validation Rule

Schema must match visible content and may not imply ratings, reviews, prices, addresses, results, or profiles that cannot be verified.

## Classification

- Google policy: structured data must follow spam policies and represent visible page content.
- SEO best practice: markup is optional and does not guarantee rich results.
