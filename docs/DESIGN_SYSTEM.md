# Design System

## Visual Direction

Web Growth should feel like a premium blend of:

- high-end SaaS
- product documentation
- structured learning platform
- founder-led digital growth consultancy

The design should communicate:

- clarity
- authority
- calm competence
- commercial seriousness

It should not feel like:

- a generic freelancer landing page
- a noisy startup hero demo
- a template-heavy “agency” theme
- a dark UI with no information density

## Existing Repo Reality

The current site already uses:

- a dark visual base
- emerald accenting
- large hero sections
- image-backed sections
- rounded cards
- translucent header shell

Future redesign work should evolve this, not randomly replace it.

## Color Palette

### Core

- Background base: near-black with subtle green tint
- Surface 1: deep charcoal
- Surface 2: dark elevated panel
- Text primary: near-white
- Text secondary: muted off-white
- Accent primary: emerald
- Accent support: restrained gold for premium emphasis only

### Rules

- Emerald remains the primary action color.
- Gold should be rare and intentional, used for premium highlights rather than general UI state.
- Avoid introducing random blues, purples, or rainbow gradients.
- Keep the palette disciplined and readable.

## Typography Approach

- Use strong, modern sans-serif display for headlines.
- Keep body text highly legible and neutral.
- Headings should feel editorial and product-grade, not flashy.
- Large display type should be reserved for real page-entry moments.
- Internal cards, panels, FAQs, and support sections should use tighter heading scales.

## Spacing System

Use a predictable spacing rhythm:

- section spacing: generous
- internal component spacing: medium
- card padding: compact to medium
- reading layouts: comfortable but not loose

Suggested mental system:

- 4
- 8
- 12
- 16
- 24
- 32
- 48
- 64
- 96

## Card Styles

Use cards only where framing is useful:

- service cards
- Academy cards
- testimonial/proof cards
- utility/tool cards
- metrics panels

Rules:

- low to medium border radius
- clear border or tonal separation
- restrained shadows
- avoid overstacked card-on-card layouts

## Section Styles

Sections should be distinct by purpose, not just by decorative variation.

Recommended section types:

1. Hero
2. Trust / proof
3. Service selection
4. Academy learning paths
5. Free tools
6. Case studies
7. CTA bands
8. Footer utility/trust block

Each section should have a strong content job.

## Dark / Light Balance

- Primary experience can remain dark.
- Reading-heavy Academy pages may benefit from lighter article surfaces inside the dark shell.
- Use contrast intentionally so content areas feel easier to read over long sessions.
- Avoid full-page visual monotony.

## Motion Rules

- CSS first
- Framer Motion only when needed
- GSAP only when the interaction truly benefits from it

Motion should be used for:

- section reveal
- hover feedback
- drawer/menu transitions
- contextual emphasis

Do not use motion for:

- constant hero distraction
- unnecessary scroll theatrics
- decorative loops with no UX value

## Premium UI Principles

1. Clarity before spectacle
2. Density without clutter
3. Proof before persuasion
4. Strong CTA hierarchy
5. Readability over visual novelty
6. Consistency across service and Academy templates

## Homepage Direction

The homepage should eventually include:

### 1. Platform hero

Explain Web Growth as a platform, not just an agency.

### 2. Core promise band

Build. Grow. Monetize.

### 3. Service engine

High-intent service pathways.

### 4. Academy learning paths

Structured content entry points by topic.

### 5. Free tools section

Utility-driven traffic and repeat visits.

### 6. Case study section

Proof and implementation depth.

### 7. Monetization trust band

Guides, tools, products, partnerships, and services working together.

### 8. Primary CTA close

Request a quote, get a review, or start with the right growth path.

## Existing Weaknesses To Correct Later

- Homepage is currently too launch-offer heavy for platform positioning.
- Navigation exposes noindex offer/campaign routes.
- Repeated image-backed panels reduce perceived system maturity.
- Some service experiences are custom while others are template-based, which weakens consistency.

## Design Decisions Future Tasks Should Preserve

- dark premium foundation
- strong action color discipline
- mobile-first layout
- generous section framing
- trust-first, content-first composition
